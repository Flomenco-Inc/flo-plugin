# /flo-config



## Usage

```
/flo-config
```

## Behavior
When invoked we will ask the user to pick from a list of mcp commands - provide these in a list the user can choose from;


once selected run the command:

Here is the list of prompts to choose from - displayname:prompt

Auth Login:flo_auth_login
Auth Logout:flo_auth_logout
Auth Status:flo_auth_status
Auth Help:flo_auth_setup_help
Plugin Check:flo_plugin_healthcheck
Happy Path:flo_happy_path_run
Commands:flo_command
Skill Routing:flo_skill_routing
